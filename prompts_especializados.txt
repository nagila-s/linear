PROMPT_CAPA
==============================
Você está lendo a capa ou folha de rosto de um livro didático. Retorne um JSON com as informações na ordem exata abaixo, omitindo apenas os campos que realmente não existirem na página.
Não descreva elementos visuais, cores ou imagens decorativas.
Retorne apenas o objeto JSON, sem markdown.

Registre cada linha de texto visível como um parágrafo separado, na ordem em que aparece na página, de cima para baixo. Não tente identificar hierarquias, títulos ou funções — cada linha é um parágrafo.

ESTRUTURA RAIZ (sempre estas três chaves na raiz):
- "tipo_pagina": tipo da página (sempre "capa")
- "pagina": número impresso na página ou "[sem página]"
- "conteudo": array com os blocos da página

{
  "tipo_pagina": "capa",
  "pagina": <número impresso na página> | "[sem página]",
  "conteudo": [
    { "tipo": "titulo_1", "texto": "<nome da coleção>" },
    { "tipo": "titulo_2", "texto": "<disciplina>" },
    { "tipo": "titulo_3", "texto": "<ano escolar ou segmento, ex: 6.º ano>" },
    { "tipo": "titulo_3", "texto": "<faixa ou volume, se houver>" },
    { "tipo": "paragrafo", "texto": "<nome(s) do(s) autor(es)>" },
    { "tipo": "paragrafo", "texto": "<nome da editora>" }
  ]
}


==============================
PROMPT_FICHA
==============================
Você está lendo a ficha catalográfica (CIP) e/ou página de créditos de um livro didático.
Registre todo o conteúdo em ordem de leitura, preservando os dados na íntegra.
A página geralmente tem dois blocos: (1) lista de papéis e responsáveis; (2) dados legais e de contato da editora.
Retorne apenas o objeto JSON, sem markdown.

Regras:
- Cada linha da lista de papéis é um item com rótulo e valor.
- Indique negrito no rótulo quando estiver em destaque visual.
- Links, e-mails e endereços eletrônicos: tipo "link".
- Endereços físicos, telefones e textos legais: tipo "paragrafo".
- A ficha CIP (dados de catalogação): tipo "ficha_catalografica".

{
  "tipo_pagina": "ficha",
  "pagina": <número impresso na página> | "[sem página]",
  "conteudo": [
    {
      "tipo": "lista",
      "tipo_lista": "descritiva",
      "itens": [
        {
          "tipo": "item",
          "marcador": "",
          "texto": [
            { "trecho": "Direção executiva: ", "estilo": "negrito" },
            { "trecho": "Nome da pessoa", "estilo": "normal" }
          ]
        }
      ]
    },
    { "tipo": "paragrafo", "texto": "Todos os direitos reservados por Saraiva Educação S.A." },
    { "tipo": "paragrafo", "texto": "Alameda Santos, 960, 4º andar\nSão Paulo – SP – CEP 01418-002\nTel.: 4003-3061" },
    { "tipo": "link", "texto": "www.edocente.com.br" },
    { "tipo": "link", "texto": "saceditorasaraiva@somoseducacao.com.br" },
    {
      "tipo": "ficha_catalografica",
      "conteudo": [
        { "campo": "Título", "valor": "Nome do livro" },
        { "campo": "ISBN", "valor": "978-00-000-000-0" },
        { "campo": "CIP", "valor": "1. Disciplina. 2. Ensino fundamental. I. Título." }
      ]
    }
  ]
}

==============================
PROMPT_SUMARIO
==============================
Você está lendo uma página de sumário ou índice de um livro didático.
Retorne apenas o objeto JSON, sem markdown.

ESTRUTURA OBRIGATÓRIA (sem ambiguidade):
- Na raiz do JSON existem APENAS três chaves: "tipo_pagina", "pagina" e "conteudo".
- "tipo_pagina" identifica o tipo da página (sempre "sumario").
- O bloco do sumário ("tipo": "sumario" e "itens") fica DENTRO do array "conteudo".
- NUNCA coloque "tipo": "sumario" nem "itens" na raiz do JSON.
- Use um único bloco "sumario" com todos os itens. Nunca represente cada entrada do índice como bloco separado.
- Se houver título visível ("SUMÁRIO", "Índice"), registre-o como titulo_3 antes do bloco sumario.

{
  "tipo_pagina": "sumario",
  "pagina": <número impresso na página> | "[sem página]",
  "conteudo": [
    { "tipo": "titulo_3", "texto": "SUMÁRIO" },
    {
      "tipo": "sumario",
      "itens": [
        { "nivel": 1, "texto": "Unidade 1 — Um novo lugar para viver", "pagina": 12 },
        { "nivel": 2, "texto": "Capítulo 1 — As migrações humanas", "pagina": 14 },
        { "nivel": 3, "texto": "Migrações hoje", "pagina": 15 }
      ]
    }
  ]
}

Os valores de "nivel" seguem a hierarquia de titulo_1 a titulo_5.
